# Masked Cell Modeling（MCM）：表格版的 BERT

## 是什么

BERT 靠「挖掉一个词、用上下文猜它」学会通用语言表示。表格基础模型用的是一样的招：
**挖掉一个格子，用同一行其它格子 + 列结构猜它**，这叫 masked cell modeling。

## 怎么做

```
输入：一张部分格子被挖掉的表
   col0   col1   col2
r0  1.0    [M]   "cat"
r1  2.0   "x"    "dog"
r2  [M]   "y"    "bird"

对每个 [M] 格子：
  1. 编码同一行其它非空格子（值嵌入 + 列嵌入 + 行嵌入）
  2. 求平均得到「行上下文」向量
  3. 过 LayerNorm + MLP 得到预测向量
  4. 分类列：把预测向量投到该列 domain 上取最大分；数值列：求和转标量
```

## 为什么这样做

1. **免标注**：掩码是自动的，任何表都能直接当训练样本。
2. **跨表泛化**：因为学习的是「从上下文补格子」这个通用能力，而不是某张表的结构，
   所以能零样本用于没见过的表。
3. **与真实补齐一致**：下游的缺失值填补，正是同一件事 —— 所以预训练任务和推理
   任务天然对齐，不需要额外的任务头设计。

本仓库实现见 `tabularforge/model/tabfm.py` 与 `tabularforge/model/mcm.py`。
