# 架构设计

tabularforge 由五层组成，全部零依赖、纯 Python：

```
┌───────────────────────────────────────────────────────────┐
│  cli / serving / integrations / examples                  │
├───────────────────────────────────────────────────────────┤
│  engine.TabularEngine（统一入口）                          │
├───────────────────────────────────────────────────────────┤
│  backends（mock / cpu / openai / vllm / transformers）     │
├───────────────────────────────────────────────────────────┤
│  model.TabFM + heads（MCM 模型与任务头）                   │
│  scm（DAG 采样 + 合成数据引擎 + 因果发现）                 │
├───────────────────────────────────────────────────────────┤
│  tabular（Table/Column + 类型推断 + 细胞编码）             │
│  core（纯 Python 张量 + nn 基础块）                        │
│  utils（确定性 RNG / 极简 YAML / 日志）                    │
└───────────────────────────────────────────────────────────┘
```

## 核心数据流

1. **合成数据**：`scm.synth.ScmSynthesizer` 采样一张因果 DAG，按拓扑序生成表格，
   每列值是「父列的函数 + 噪声」。于是每张表都自带真值，可无限生成、不碰真实数据。
2. **细胞编码**：`tabular.encoder.CellEncoder` 把每个格子编码成「值嵌入 + 列嵌入 +
   行嵌入」之和，任何形状的表都坍缩到同一个定宽向量。
3. **掩码建模**：`model.TabFM` 把缺失格子的「行内其它格子」聚合为上下文，过 MLP
   预测该格子。训练目标 = 掩码语言建模（对表格而言是 masked cell modeling）。
4. **零样本补全**：预训练后，给定带空格的表，直接 `impute`，无需任何额外训练。

## 关键决策

- **确定性优先**：所有随机性都走 `utils.stable`（md5 前 8 字节做种子），同输入必
  同输出，方便复现与测试。
- **后端可替换**：`get_backend(name, cfg)` 按名实例化，CLI / 服务 / 基准三处复用。
- **零依赖**：无 numpy / pandas / torch，任何 Python 3.9+ 都能跑。
