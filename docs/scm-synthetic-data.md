# 结构因果模型（SCM）合成数据：不碰真实数据也能训练

## 为什么 Kumo Tabular 只在合成表上预训练

真实表格数据有几个致命问题：隐私（不能拿客户数据）、版权、格式脏、量有限。Kumo 的
做法是**完全不看真实数据**，而是从结构因果模型（SCM）采样出无限张「人造表」。

## 怎么做

1. **采样 DAG**：`scm.dag.sample_dag(n, edge_prob)` 生成一张有向无环图，节点 j 只
   依赖编号更小的 i（天然无环）。
2. **按拓扑序生成**：每列的值 = 父列值的函数 + 噪声。
   - 数值列：`value = Σ w·parent + noise`
   - 分类列：`value = truth_table(parents, noise)`
   - 日期列：`day = hash(parents) + noise`
3. **自带真值**：因为父集已知，每个格子都能从父列唯一推回，于是天然有监督信号。

## 为什么这样做

- **无限数据**：DAG 和噪声空间是无限的，想生成多少生成多少。
- **零隐私风险**：所有表都是人造的，不含任何真实记录。
- **已知因果结构**：顺带可以做因果发现（`scm.causal.discover_parents`）并与真值
  对拍，验证方法本身。

实现见 `tabularforge/scm/synth.py`。
